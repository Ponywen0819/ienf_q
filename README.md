## 1. 系統概述

### 1.1 系統定位

**核心定位**: 基於傳統演算法的神經纖維重建系統

**系統目標**: 從稀疏的人工標註片段重建完整的神經纖維網絡結構

**系統特點**:

- **可解釋性**: 每個步驟的邏輯清晰明確
- **可控性**: 參數可調整,易於針對不同影像優化
- **穩定性**: 不依賴大量訓練數據
- **可視化**: 中間結果可檢視,便於除錯和改進

**系統價值**:

- 從不連續的標註區塊生成連續的神經網絡結構
- 保留神經纖維的真實幾何特徵（彎折、分支）
- 提供高品質的重建結果供後續分析或標註

### 1.2 輸入數據特性

**切片染色影像**:

- RGB 彩色影像
- 神經組織在綠色通道有較強響應
- 紅色通道為其他染料(可能干擾綠色通道)

**標註數據**:

- 形式: 不連續的白色區塊
- 性質: 人工標記的神經纖維片段
- 覆蓋範圍: 僅標記表皮上方
- 特點: 同一條神經可能有多個分離區塊

**關鍵挑戰**:

- 標註區塊之間存在空白,需要推斷連接關係
- 神經纖維可能有複雜的彎折和分支結構
- 背景染色不均勻,影像品質有變化
- 紅色通道可能干擾綠色通道的神經纖維訊號

### 1.3 輸出結果

**重建結果**:

- 完整的神經纖維網絡結構
- 圖結構表示（節點 + 邊）
- 神經纖維的連續路徑

**可視化輸出**:

- 種子點標記
- 連接路徑繪製
- MST/森林結構圖
- 品質評估報告

**後續應用**:

- 神經纖維密度分析
- 形態學特徵提取
- 作為深度學習訓練數據（可選）

## 2. 傳統重建演算法流程

### 階段零: 影像前處理

**目標**: 改善影像品質,增強神經纖維訊號

**輸入**: RGB 彩色影像
**使用通道**: 綠色通道（神經組織有較強響應）

**注意**:

- 紅色通道可能包含其他染料,會有一定干擾
- 若後續發現紅色干擾嚴重,可考慮加入通道去耦合步驟
- 現階段先直接使用綠色通道,簡化流程

#### 0.1 背景不均校正

**方法**: Rolling Ball 背景扣除

**原理**:

- 模擬球體在影像強度表面下方滾動
- 球接觸的表面視為背景
- 從原影像扣除背景

**參數**:

- ball_radius: 40-60 像素
- 應大於神經纖維最大寬度

#### 0.2 局部對比度增強

**方法**: CLAHE (對比度受限自適應直方圖均衡化)

**參數**:

- tile_size: 8×8 或 16×16
- clip_limit: 2.0-4.0

**效果**:

- 平衡不同區域亮度
- 增強局部對比度
- 提升神經纖維與背景的對比

#### 0.3 標準化

**方法**: 百分位數標準化

- 計算 1%和 99%百分位數
- 裁剪極端值
- 映射到[0, 255]

**輸出**: 校正後的綠色通道影像,用於所有後續步驟

---

### 階段一: 種子點提取

**目標**: 從標註區塊提取代表性種子點

#### 1.1 連通元件分析

**輸入**: 二值標註影像
**處理**: 提取所有獨立白色區塊
**輸出**: 各連通元件的 mask

#### 1.2 骨架化與結構分析

**對每個連通元件**:

- 執行形態學骨架化
- 分析骨架結構(端點、分支點、路徑)
- 計算骨架長度和複雜度

#### 1.3 曲率感知的種子提取

**核心理念**: 在神經彎折處必須放置種子點

**問題**:

```
如果彎折處缺少種子:
- 後續MST會因曲率成本懲罰將彎折拉直
- 導致重建失敗
```

**解決方案**: 基於曲率的自適應分段

**算法流程**:

```
1. 沿骨架行進,累積路徑長度

2. 持續監測局部曲率:
   - 使用滑動窗口(5個像素)
   - 計算前後方向向量夾角

3. 在以下情況創建種子:
   ├─ 達到基礎分段長度(10像素)
   ├─ 檢測到顯著彎折(曲率 > 30度) ← 優先級最高
   └─ 路徑過長(20像素,防呆)

4. 種子位置:
   └─ 取該段骨架的中心點
```

**曲率計算**:

```
對骨架點 i:
1. 取局部窗口點集 [i-w, ..., i, ..., i+w]
2. 分為前半和後半
3. 計算前半段方向向量 v1
4. 計算後半段方向向量 v2
5. 曲率 = arccos(v1·v2 / |v1||v2|)
```

**關鍵點檢測**(輔助):

- 端點: 骨架末端(鄰居數=1)
- 分支點: 骨架分岔(鄰居數>=3)
- 強制作為種子

**輸出**:

- 種子點座標列表
- 種子-元件映射關係
- 種子類型標記(端點/分支點/彎折點/中間點)

---

### 階段二: 連接圖構建

**目標**: 建立種子間的連接關係和成本

#### 2.1 種子配對策略

**元件內配對**:

```
同一標註區塊的種子:
- 自動建立連接
- 成本 = 歐式距離(或骨架距離)
- 標記為"元件內邊"
```

**元件間配對**:

```
不同標註區塊的種子:
- 需滿足距離條件
- 使用多因素成本函數
- 標記為"元件間邊"
```

#### 2.2 自適應配對半徑

**問題**: 固定半徑無法適應不同區域的神經密度

**方法**: 根據局部種子密度調整

```
計算種子到最近k個鄰居的平均距離:

密集區域 (平均距離 < 30px):
└─ radius = 30px

適中區域 (30-70px):
└─ radius = 50px

稀疏區域 (> 70px):
└─ radius = 80px
```

#### 2.3 多因素成本函數

**公式**:

```
總成本 = α × 幾何成本 + β × 影像成本 + γ × 曲率成本

建議權重:
α = 0.3 (幾何距離)
β = 0.5 (影像特徵,最重要)
γ = 0.2 (曲率約束)
```

**成本分量**:

**1. 幾何成本**:

- 定義: 歐式距離
- 作用: 偏好連接較近的種子

**2. 影像特徵成本**:

```
核心思想: 路徑應沿高綠色區域(神經組織)

實現:
1. 構建成本地圖: cost_map = 255 - green_channel
2. 使用A*或Dijkstra在成本地圖上找最短路徑
3. 成本 = 路徑總成本 / 路徑長度(標準化)
```

**3. 曲率成本**:

```
核心思想: 懲罰過度彎曲路徑(神經不會急劇轉彎)

曲折度指標:
tortuosity = 實際路徑長度 / 直線距離

懲罰函數:
if tortuosity < 1.5:
    成本 = 0
else:
    成本 = (tortuosity - 1) × 100
```

#### 2.4 圖結構

**節點**: 所有種子點
**邊**: 滿足配對條件且成本 < 閾值的種子對
**權重**: 多因素成本

---

### 階段三: 最小生成樹重建

**目標**: 提取最優神經網絡拓撲

#### 3.1 約束 MST 計算

**標準 MST 問題**:

- 可能產生不合理連接
- 強制單一連通樹,但神經可能有多個分離網絡

**改進**: 約束 MST

```
策略:
1. 設定最大可接受成本(如150)
2. 拒絕成本超過上限的邊
3. 允許產生森林(多個連通分量)

結果:
- 合理連接被保留
- 不確定的連接被拒絕
- 可能產生多個分離的神經網絡
```

#### 3.2 後處理與驗證

**交叉邊檢測**:

- 檢查邊是否在空間上交叉
- 交叉可能表示拓撲錯誤

**銳角分支檢測**:

- 檢查分支點角度
- 神經通常不形成銳角分支(< 30 度)

**路徑質量評估**:

- 檢查邊的路徑是否沿高綠色區域
- 計算路徑平均綠色強度
- 標記低質量路徑

**輸出**:

- MST/森林結構
- 驗證報告(潛在問題列表)
- 可視化結果

## 3. 關鍵演算法總結

### 3.1 核心創新點

**曲率感知的種子提取**:

- 在彎折處強制放置種子
- 避免 MST 將神經拉直
- 保留真實幾何結構

**多因素成本函數**:

- 結合幾何、影像、曲率
- 確保連接沿神經組織
- 避免不合理路徑

**約束 MST**:

- 拒絕高成本邊
- 允許多連通分量
- 更符合真實神經網絡

### 3.2 參數建議

**前處理**:

- 通道去耦合: α = 0.2-0.5
- Rolling Ball: radius = 50px
- CLAHE: clip_limit = 3.0, tile_size = 8×8

**種子提取**:

- 基礎分段長度: 25px
- 曲率閾值: 30 度
- 最小種子間距: 10px

**圖構建**:

- 配對半徑: 30-80px (自適應)
- 成本權重: α=0.3, β=0.5, γ=0.2
- 最大邊成本: 150

## 4. 實作建議與預期效果

### 4.1 開發流程建議

**階段一: 基礎功能開發**

```
1. 實作影像前處理模組
   - 通道去耦合
   - 背景校正
   - CLAHE 增強

2. 實作種子點提取
   - 連通元件分析
   - 骨架化
   - 基礎種子提取

3. 測試與視覺化
   - 檢視前處理效果
   - 檢視種子點分布
```

**階段二: 核心演算法開發**

```
1. 實作曲率感知機制
   - 曲率計算
   - 自適應分段
   - 關鍵點檢測

2. 實作圖構建
   - 配對策略
   - 成本函數
   - A*路徑搜尋

3. 實作MST重建
   - Kruskal/Prim演算法
   - 約束條件
   - 森林結構
```

**階段三: 優化與驗證**

```
1. 參數調優
   - 針對不同影像調整參數
   - 建立參數配置檔

2. 後處理與驗證
   - 交叉邊檢測
   - 路徑品質評估
   - 結果可視化

3. 批次處理
   - 多影像處理流程
   - 結果統計與分析
```

### 4.2 預期效果

**連通性**:

- 同一神經纖維的標註區塊應正確連接
- 不同神經纖維不應錯誤連接
- 目標準確率: > 90%

**幾何保真度**:

- 保留真實的彎折結構
- 分支點正確識別
- 路徑平滑且自然

**處理能力**:

- 單張影像處理時間: < 30 秒
- 可處理複雜的神經網絡結構
- 對不同影像品質有一定容忍度

### 4.3 已知限制

**影像品質要求**:

- 需要可見的綠色通道神經訊號
- 過度模糊的影像可能失敗
- 嚴重染色不均需要更多前處理

**標註要求**:

- 標註應覆蓋主要神經纖維
- 過度稀疏的標註可能導致錯誤連接
- 建議每條神經至少有 2-3 個標註區塊

**複雜結構**:

- 密集交錯的神經網絡較具挑戰性
- 可能需要人工審核和修正
- 極端彎折或分支可能需要參數調整

### 4.4 後續改進方向

**演算法改進**:

- 引入機器學習輔助路徑選擇
- 更智能的自適應參數調整
- 基於模板匹配的局部優化

**功能擴展**:

- 交互式編輯工具（手動調整連接）
- 批次處理與統計分析
- 3D 重建（多切片整合）

**效能優化**:

- 並行處理加速
- GPU 加速路徑搜尋
- 多解析度處理策略
