# 神經纖維重建系統建構計劃 v3.0

## 文檔修訂歷史

- v1.0 (2025-10-12): 初始版本
- v2.0 (2025-10-12): 修正標註理解,新增彎折檢測與曲率感知機制
- v3.0 (2025-10-12):
  - 重新定位系統角色為訓練數據生成器
  - 新增深度學習模型訓練策略
  - 加入 domain adaptation 方法
  - 聚焦演算法核心內容

## 1. 系統概述

### 1.1 系統定位

**核心定位**: 神經纖維重建系統,採用**兩階段混合策略**

**兩階段策略**:

**階段 I: 傳統演算法重建 (Bootstrapping 階段)**

```
目標: 生成訓練數據
流程:
1. 使用傳統方法重建表皮上方神經纖維
2. 人工審核並修正,生成高品質ground truth
3. 構建訓練數據集
```

**階段 II: 深度學習模型 (Production 階段)**

```
目標: 端到端神經分割
流程:
1. 訓練U-Net模型
2. 使用Domain Adaptation處理表皮上下方差異
3. 部署模型進行快速分割
```

**系統特點**:

- **傳統方法**: 可解釋、可控、適合數據準備
- **深度學習**: 快速、端到端、適合生產部署
- **混合優勢**: 結合兩者優點,先用傳統方法生成數據,再用深度學習提升效能

**系統價值**:

- 從稀疏標註生成密集的完整神經網絡結構
- 傳統方法作為數據生成器和品質保證
- 深度學習作為最終生產工具
- 兩階段互補,系統更健壯

### 1.2 輸入數據特性

**切片染色影像**:

- RGB 彩色影像
- 神經組織在綠色通道有較強響應
- 紅色通道為其他染料(可能干擾綠色通道)

**標註數據**:

- 形式: 不連續的白色區塊
- 性質: 人工標記的神經纖維片段
- 覆蓋範圍: 僅標記表皮上方
- 特點: 同一條神經可能有多個分離區塊

**關鍵挑戰**:

- 表皮上方與下方存在差異(紅色染料密度不同)
- 前處理需要盡可能統一上下方的影像特性
- 如前處理不完全有效,需要 domain adaptation

### 1.3 輸出結果

**階段 I 輸出**(傳統重建):

- 表皮上方的完整神經纖維網絡結構
- 圖結構(節點+邊)
- 可視化結果

**階段 II 輸出**(人工審核後):

- 高品質的神經纖維 mask
- 標註品質評分
- 用於深度學習訓練

**階段 III 輸出**(模型訓練後):

- 訓練好的 U-Net 模型
- 能端到端預測完整神經分割

## 2. 傳統重建演算法流程

### 階段零: 影像前處理

**目標**: 消除通道干擾與亮度不均,統一表皮上下方的影像特性

#### 0.1 通道去耦合

**問題**: 紅色通道(其他染料)干擾綠色通道(神經纖維)

**方法**: 線性校正

```
Green_corrected = Green_original - α × Red

參數 α:
- 基礎值: 0.2
- 表皮下方紅色密度高時: 可能需要 0.3-0.5
- 需要根據實際影像調整
```

**自適應策略**(可選):

- 根據區域紅色密度動態調整 α
- 表皮上方: α 較小
- 表皮下方: α 較大
- 使用平滑過渡避免邊界偽影

#### 0.2 背景不均校正

**方法**: Rolling Ball 背景扣除

**原理**:

- 模擬球體在影像強度表面下方滾動
- 球接觸的表面視為背景
- 從原影像扣除背景

**參數**:

- ball_radius: 40-60 像素
- 應大於神經纖維最大寬度

#### 0.3 局部對比度增強

**方法**: CLAHE (對比度受限自適應直方圖均衡化)

**參數**:

- tile_size: 8×8 或 16×16
- clip_limit: 2.0-4.0

**效果**:

- 平衡不同區域亮度
- 增強局部對比度
- 使表皮上下方的綠色通道品質更接近

#### 0.4 標準化

**方法**: 百分位數標準化

- 計算 1%和 99%百分位數
- 裁剪極端值
- 映射到[0, 255]

**輸出**: 校正後的綠色通道影像,用於所有後續步驟

---

### 階段一: 種子點提取

**目標**: 從標註區塊提取代表性種子點

#### 1.1 連通元件分析

**輸入**: 二值標註影像
**處理**: 提取所有獨立白色區塊
**輸出**: 各連通元件的 mask

#### 1.2 骨架化與結構分析

**對每個連通元件**:

- 執行形態學骨架化
- 分析骨架結構(端點、分支點、路徑)
- 計算骨架長度和複雜度

#### 1.3 曲率感知的種子提取

**核心理念**: 在神經彎折處必須放置種子點

**問題**:

```
如果彎折處缺少種子:
- 後續MST會因曲率成本懲罰將彎折拉直
- 導致重建失敗
```

**解決方案**: 基於曲率的自適應分段

**算法流程**:

```
1. 沿骨架行進,累積路徑長度

2. 持續監測局部曲率:
   - 使用滑動窗口(5個骨架點)
   - 計算前後方向向量夾角

3. 在以下情況創建種子:
   ├─ 達到基礎分段長度(25像素)
   ├─ 檢測到顯著彎折(曲率 > 30度) ← 優先級最高
   └─ 路徑過長(50像素,防呆)

4. 種子位置:
   └─ 取該段骨架的中心點
```

**曲率計算**:

```
對骨架點 i:
1. 取局部窗口點集 [i-w, ..., i, ..., i+w]
2. 分為前半和後半
3. 計算前半段方向向量 v1
4. 計算後半段方向向量 v2
5. 曲率 = arccos(v1·v2 / |v1||v2|)
```

**關鍵點檢測**(輔助):

- 端點: 骨架末端(鄰居數=1)
- 分支點: 骨架分岔(鄰居數>2)
- 強制作為種子

**策略分類**:

```
小元件 (< 100px):
└─ 單一種子(質心或綠通道最強點)

中等元件:
└─ 曲率感知的自適應分段

大型複雜元件 (> 1000px):
└─ 曲率分段 + 關鍵點檢測 + 去重
```

**輸出**:

- 種子點座標列表
- 種子-元件映射關係
- 種子類型標記(端點/分支點/彎折點/中間點)

---

### 階段二: 連接圖構建

**目標**: 建立種子間的連接關係和成本

#### 2.1 種子配對策略

**元件內配對**:

```
同一標註區塊的種子:
- 自動建立連接
- 成本 = 歐式距離(或骨架距離)
- 標記為"元件內邊"
```

**元件間配對**:

```
不同標註區塊的種子:
- 需滿足距離條件
- 使用多因素成本函數
- 標記為"元件間邊"
```

#### 2.2 自適應配對半徑

**問題**: 固定半徑無法適應不同區域的神經密度

**方法**: 根據局部種子密度調整

```
計算種子到最近k個鄰居的平均距離:

密集區域 (平均距離 < 30px):
└─ radius = 30px

適中區域 (30-70px):
└─ radius = 50px

稀疏區域 (> 70px):
└─ radius = 80px
```

#### 2.3 多因素成本函數

**公式**:

```
總成本 = α × 幾何成本 + β × 影像成本 + γ × 曲率成本

建議權重:
α = 0.3 (幾何距離)
β = 0.5 (影像特徵,最重要)
γ = 0.2 (曲率約束)
```

**成本分量**:

**1. 幾何成本**:

- 定義: 歐式距離
- 作用: 偏好連接較近的種子

**2. 影像特徵成本**:

```
核心思想: 路徑應沿高綠色區域(神經組織)

實現:
1. 構建成本地圖: cost_map = 255 - green_channel
2. 使用A*或Dijkstra在成本地圖上找最短路徑
3. 成本 = 路徑總成本 / 路徑長度(標準化)
```

**3. 曲率成本**:

```
核心思想: 懲罰過度彎曲路徑(神經不會急劇轉彎)

曲折度指標:
tortuosity = 實際路徑長度 / 直線距離

懲罰函數:
if tortuosity < 1.5:
    成本 = 0
else:
    成本 = (tortuosity - 1) × 100
```

#### 2.4 圖結構

**節點**: 所有種子點
**邊**: 滿足配對條件且成本 < 閾值的種子對
**權重**: 多因素成本

---

### 階段三: 最小生成樹重建

**目標**: 提取最優神經網絡拓撲

#### 3.1 約束 MST 計算

**標準 MST 問題**:

- 可能產生不合理連接
- 強制單一連通樹,但神經可能有多個分離網絡

**改進**: 約束 MST

```
策略:
1. 設定最大可接受成本(如150)
2. 拒絕成本超過上限的邊
3. 允許產生森林(多個連通分量)

結果:
- 合理連接被保留
- 不確定的連接被拒絕
- 可能產生多個分離的神經網絡
```

#### 3.2 後處理與驗證

**交叉邊檢測**:

- 檢查邊是否在空間上交叉
- 交叉可能表示拓撲錯誤

**銳角分支檢測**:

- 檢查分支點角度
- 神經通常不形成銳角分支(< 30 度)

**路徑質量評估**:

- 檢查邊的路徑是否沿高綠色區域
- 計算路徑平均綠色強度
- 標記低質量路徑

**輸出**:

- MST/森林結構
- 驗證報告(潛在問題列表)
- 可視化結果

## 3. 深度學習模型訓練策略

### 階段四: 訓練數據準備

#### 4.1 數據生成流程

```
步驟1: 使用傳統重建生成初步結果
├─ 輸入: 前處理後的影像 + 表皮上方標註
├─ 輸出: 完整神經纖維網絡結構
└─ 轉換為二值mask

步驟2: 人工審核與修正 ⭐
├─ 視覺化檢查重建結果
├─ 品質評分: 優秀/良好/不良
├─ 人工修正:
│   ├─ 刪除錯誤連接
│   ├─ 添加遺漏連接
│   ├─ 調整彎折形狀
│   └─ 標記置信度區域
└─ 輸出: 高品質ground truth mask

步驟3: 構建訓練數據集
├─ 配對: (前處理影像, 修正後mask)
├─ 數據增強:
│   ├─ 幾何變換: 旋轉、翻轉、彈性形變
│   ├─ 亮度對比度調整
│   └─ 增加噪聲
├─ 擴增到: 200-500對
└─ 分割: 訓練70% / 驗證15% / 測試15%
```

#### 4.2 數據收集建議

```
表皮上方標註影像: 50-100張
├─ 用於生成訓練數據
└─ 必須經過人工審核修正

表皮下方無標註影像: 100-200張
├─ 用於domain adaptation
└─ 不需要標註

表皮下方標註影像: 5-10張
├─ 用於驗證和最終微調
└─ 少量但重要
```

### 階段五: 基礎模型訓練

#### 5.1 模型架構

**U-Net**:

```
結構:
├─ Encoder (下採樣路徑)
│   └─ 提取多尺度特徵
├─ Bottleneck (最深層)
│   └─ 最抽象的特徵表達
└─ Decoder (上採樣路徑)
    └─ 結合skip connections重建細節

輸入: 前處理後的綠色通道(或RGB)
輸出: 神經纖維概率圖(0-1)
```

**改進選項**:

- Attention U-Net: 加入注意力機制
- U-Net++: 密集連接
- ResU-Net: 殘差連接

#### 5.2 訓練配置

**損失函數**:

- Dice Loss (處理類別不平衡)
- 或 Focal Loss
- 或組合損失

**優化器**: Adam, 學習率 1e-4

**訓練策略**:

- Batch size: 4-8
- Epochs: 50-100
- Early stopping
- 學習率衰減

**監控指標**:

- Dice 係數
- IoU (Intersection over Union)
- 精確率 / 召回率

### 階段六: Domain Adaptation (表皮下方適應)

**問題**: 儘管前處理有幫助,表皮上下方仍可能有分布差異

**目標**: 讓在上方訓練的模型也能處理下方

#### 6.1 初步評估

```
步驟:
1. 用階段五訓練的模型預測表皮下方
2. 視覺檢查效果
3. 評估是否需要domain adaptation

決策:
├─ 如果下方效果 > 60%: 使用偽標籤法
└─ 如果下方效果 < 60%: 使用對抗式domain adaptation
```

---

#### 6.2 方法 A: 偽標籤法 (Pseudo-Labeling)

**適用**: 模型在下方已有一定效果

**核心思想**:

```
迭代式自我改進:
1. 用當前模型預測表皮下方
2. 選擇高置信度預測作為"偽標籤"
3. 用偽標籤擴充訓練集
4. 重新訓練得到更好模型
5. 重複迭代
```

**置信度選擇策略**:

**方法 1: 基於預測概率**

```
模型輸出0-1的概率圖:
- 只使用概率 > 0.9 或 < 0.1 的像素
- 中間不確定區域忽略
- 避免引入錯誤標籤
```

**方法 2: 基於預測一致性**

```
訓練多個模型(不同初始化):
- 只使用所有模型預測一致的區域
- 不一致區域視為不可靠
- 提高偽標籤品質
```

**訓練流程**:

```
迭代 0:
└─ 基礎模型(僅上方數據)

迭代 1:
├─ 用基礎模型預測下方
├─ 選擇高置信度區域(閾值 > 0.95)
├─ 訓練集 = 上方(真實標註) + 下方(偽標籤,權重0.5)
└─ 得到模型 v2

迭代 2:
├─ 用模型v2預測下方
├─ 降低閾值(> 0.85),擴展偽標籤
├─ 重新訓練
└─ 得到模型 v3

...重複3-5輪直到收斂
```

**風險控制**:

- 嚴格的置信度閾值
- 降低偽標籤損失權重(如 0.5)
- 定期人工檢查偽標籤品質
- 如果性能下降立即停止

---

#### 6.3 方法 B: 對抗式 Domain Adaptation

**適用**: 模型在下方效果差,或需要更強適應能力

**核心思想**:

```
訓練兩個網絡對抗:
1. 分割網絡: 學習分割神經纖維
2. 域判別器: 判斷特徵來自上方還是下方

目標:
- 判別器想正確區分域
- 分割網絡想騙過判別器
- 結果: 學到域不變的特徵
```

**網絡架構**:

```
輸入影像(上方或下方)
    ↓
┌──────────────┐
│ Encoder      │ ← 特徵提取(共享)
│ (U-Net)      │
└──────────────┘
    ↓
  特徵 f
    ↓
    ├─────────────┬──────────────┐
    ↓             ↓              ↓
┌─────────┐  ┌─────────┐  ┌──────────┐
│ Decoder │  │ Domain  │  │ Gradient │
│         │  │ Discrim │  │ Reversal │
│(分割)   │  │         │  │  Layer   │
└─────────┘  └─────────┘  └──────────┘
    ↓             ↓
  分割mask    域分類(上/下)
```

**Gradient Reversal Layer**:

```
作用:
- 前向傳播: 正常計算
- 反向傳播: 反轉梯度

效果:
- 判別器學習區分域
- 但編碼器接收反向梯度
- 編碼器被迫產生域不變特徵
```

**訓練過程**:

**階段 A: 源域預訓練 (Epoch 1-20)**

```
只用表皮上方數據:
- 訓練基礎分割能力
- λ_adversarial = 0 (不啟用對抗)
- 確保模型基礎能力
```

**階段 B: 對抗訓練 (Epoch 21-50)**

```
同時使用上方(有標註) + 下方(無標註):

對上方影像:
├─ 分割損失: L_seg = Dice_Loss(預測, 真實)
└─ 域判別損失: 標籤 = 0 (上方)

對下方影像:
└─ 域判別損失: 標籤 = 1 (下方)
    (無分割損失,因為沒有標註)

總損失:
L_total = L_seg + λ × L_adversarial

λ 逐漸增加: 0 → 0.1 → 1.0
alpha (GRL強度) 逐漸增加: 0 → 1.0
```

**階段 C: 穩定訓練 (Epoch 51-100)**

```
λ 固定
監控上下方的性能
Early stopping
```

**損失函數細節**:

```
分割損失(僅源域):
L_seg = Dice_Loss(source_pred, source_label)

域判別損失(源域+目標域):
L_domain = CrossEntropy(source_domain_pred, [0, 0, ...]) +
           CrossEntropy(target_domain_pred, [1, 1, ...])

對抗損失:
L_adversarial = -L_domain (反轉符號)
```

---

#### 6.4 方法 C: 自監督預訓練 (可選)

**適用**: 有大量無標註影像

**核心思想**:

```
在使用標註數據前:
1. 先在無標註影像上預訓練
   - 包括上方和下方的大量影像
2. 學習通用的影像特徵表達
3. 再用標註數據微調
```

**自監督任務選項**:

**對比學習**:

```
原理:
- 同一影像的不同增強版本應相似
- 不同影像應不同

```

## 5. 關鍵演算法總結

### 5.1 核心創新點

**曲率感知的種子提取**:

- 在彎折處強制放置種子
- 避免 MST 將神經拉直
- 保留真實幾何結構

**多因素成本函數**:

- 結合幾何、影像、曲率
- 確保連接沿神經組織
- 避免不合理路徑

**約束 MST**:

- 拒絕高成本邊
- 允許多連通分量
- 更符合真實神經網絡

**Domain Adaptation**:

- 處理表皮上下方差異
- 對抗式訓練或偽標籤
- 擴展模型適用範圍

### 5.2 參數建議

**前處理**:

- 通道去耦合: α = 0.2-0.5
- Rolling Ball: radius = 50px
- CLAHE: clip_limit = 3.0, tile_size = 8×8

**種子提取**:

- 基礎分段長度: 25px
- 曲率閾值: 30 度
- 最小種子間距: 10px

**圖構建**:

- 配對半徑: 30-80px (自適應)
- 成本權重: α=0.3, β=0.5, γ=0.2
- 最大邊成本: 150

**模型訓練**:

- 學習率: 1e-4
- Batch size: 4-8
- Domain adaptation λ: 0.1-1.0
